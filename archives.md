# Archives

## Extract `.tar.gz` files

Use the `tar` command:

```bash
tar -x -f file.tar.gz
```

+ `-x`: Extract files.
+ `-f`: Specify which file to extract.

---

## Zip Files

```bash
# Extract zip files:
unzip archive.zip

# Create zip files
zip output.zip file
zip -r output.zip directory
```
